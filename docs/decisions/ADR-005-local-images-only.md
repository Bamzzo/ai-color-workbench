# ADR-005：本地图片默认不上云

## 状态

已采用（P0）。

## 背景

本项目的核心调色与渲染完全在本地完成。AI 只负责把自然语言转成受约束参数，
不需要也不应该看到照片。

## 决策

1. 发往 AI 服务的内容只有：用户文字描述（≤2000 字符）、ColorParams v1 规范说明、
   可选的当前参数。
2. 不发送图像像素、缩略图、EXIF、源图路径、文件名、LUT 文件或渲染结果。
3. 日志只记录 request_id、provider、model、attempt、耗时和错误码；不记录密钥、
   完整 Authorization 头或用户描述正文。
4. 缺少密钥或 `AI_OFFLINE_ONLY=true` 时完全不发起网络请求，直接使用离线模板，
   并在 UI 中标记来源为“离线模板”。
5. 参考图/多图语义属于 P2，不在 P0 实现。

## 后果

- 用户可以离线完成全部图像处理；在线 AI 只是可选的参数建议器。
- 任何“上传参考图”的 P2 功能都必须新增 ADR 和明确的用户确认，不得默认开启。
- 测试用注入式 HTTP transport 检查请求体，确认没有像素或路径字段。
