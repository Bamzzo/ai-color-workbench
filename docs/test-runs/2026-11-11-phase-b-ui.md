# 2026-11-11 阶段 B（批次窗口 UI + 参数填充 + 源变化检测）

## 范围

在逻辑层与 worker 已通过验证的基础上，接 `app/batch_ui.py` 批次窗口、主窗口互锁、
“用当前参数填充所选 / 恢复统一参数”两个参数操作，以及执行前的源变化检测与
输出目录可写预检。对应《开发指导》§3.2（批次工作区）、§4.3（参数策略）、
§5（执行前校验）、§10（外部修改）。

## 覆盖

UI 生命周期：窗口创建/关闭、关闭后释放互锁、缩略图（图片 + 视频首帧）、
列表行与状态列、批次结束后汇总文案。

参数：填充只作用于所选且待处理的项；行内“参数”列在 `统一`/`单独` 间切换；
清除只影响所选；运行中两个按钮禁用；开始导出时用编辑器当前参数刷新基线。

互锁：批次运行中 `open_btn`/导出按钮为 disabled，`load_path` 与 `export_image`
返回提示而不执行；批次结束后恢复；窗口关闭同样恢复。

预检：输出目录不存在/不可写时拒绝开始（走提示而非异常）；无单素材导出在途。

源变化：导入后修改文件会在规划阶段报 `SOURCE_CHANGED`，重试不会绕过，
必须重新导入。

## 写入与清理

- 单元测试只用 `tempfile.mkdtemp` + `rmtree`，不写 `runtime/`。
- `batch_ui_check.py` 全部输入/输出在 `tempfile.mkdtemp(prefix="batch-ui-check-")`
  内，结束时整体删除；视频由 ffmpeg 的 `testsrc2` 合成。

- 未触碰用户素材。

## 2026-11-11 修复：批次窗口显示问题（用户实测反馈）

实测截图暴露了三个问题，均已修复：

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 缩略图压住相邻行的文字，行与行重叠 | `Treeview` 未设 `rowheight`，默认行高约 20 px 而缩略图 84 px | 缩略图改为 64 px、行高 68 px，并按显示缩放换算（125%/150% 同步放大） |
| 文件名完全不显示 | 该 Tk/主题组合下，带 `-image` 的树项不绘制自身 `-text` | 树列只放缩略图，文件名改为普通值列 `name`，稳定绘制 |
| 「取消后续」「全部取消」被右边缘裁掉，“JPEG 质量”缩成“JPE” | 单行塞入 7 个按钮与 5 组配置 | 配置拆两行、操作按钮拆三行（文件 / 运行控制 / 参数） |
| 「尺寸/时长」显示 `1920×128` 被截 | 列宽不足 | 固定列配上 `minwidth`，默认总宽 980 px 适配默认窗口，更窄时横向滚动 |

回归保护：`runtime/batch_ui_check.py` 新增行高 ≥ 缩略图、三行按钮宽度不越界、
每行 `name` 列内容与 `image` 存在的断言。

截图：`docs/test-runs/evidence/2026-11-11-ui-acceptance/05-batch-window-fixed.png`。

排查过程中的教训：用 `ImageGrab` 截图前必须确认窗口在最前，否则抓到的是桌面
背景（本次一度因此误判“文字消失”的原因）；窗口被遮挡时改用 `PrintWindow`。

## 未验证 / 仍待人工验收

- 高 DPI（125%/150%）、最小窗口、长文件名下列表与两行按钮不重叠。
- 批次窗口内直接“编辑某项参数”的完整编辑器：当前只支持“用编辑器当前参数填充”
  与“恢复统一参数”，没有独立的单项滑块面板。
- 暂停/继续、批次落盘续跑、磁盘空间预估、参考素材协调：按 ADR-010 推迟。
- 长批次内存曲线（阶段 D）。
